# Расписание МАП-М26

Расписание 1 семестра 2026/27 группы МАП-М26 (РГГМУ, метеорологический факультет,
05.04.05 «Прикладная гидрометеорология», профиль «Моделирование атмосферных процессов»).

**Приложение:** <https://nerpa-ai.github.io/schedule/mapm26-raspisanie/>
**Репозиторий:** <https://github.com/Nerpa-ai/schedule> — приложение лежит в папке `mapm26-raspisanie/`

Одностраничное веб-приложение без сборки и без зависимостей: открывается в браузере,
ставится на домашний экран iPhone как обычное приложение и работает без интернета.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Всё приложение: разметка, стили, данные расписания и логика |
| `manifest.webmanifest` | Имя, иконки и режим запуска для установки на телефон |
| `sw.js` | Service worker: офлайн-режим |
| `icon-180.png` | Иконка для домашнего экрана iOS |
| `icon-192.png`, `icon-512.png` | Иконки для Android и манифеста |

Период теоретического обучения: 01.09.2026 — 13.12.2026 (15 недель).
Занятия хранятся либо конкретными датами, либо диапазоном — как в исходном PDF,
поэтому пара не показывается после окончания своего периода.

## Установка на iPhone

1. Откройте <https://nerpa-ai.github.io/schedule/mapm26-raspisanie/> **в Safari**.
   Не в Chrome: на iOS только Safari умеет добавлять сайты на домашний экран.
   Слэш в конце адреса обязателен.
2. Дождитесь, пока расписание прорисуется.
3. Кнопка **Поделиться** — квадрат со стрелкой вверх внизу экрана по центру
   (в ландшафтной ориентации — справа вверху).
4. Пролистайте список вниз до пункта **На экран «Домой»**.
5. Сверху появится имя **МАП-М26** и иконка. Нажмите **Добавить**.

Запуск с иконки открывает расписание на весь экран, без адресной строки.
После первого открытия страница кэшируется и работает без интернета —
проверить можно в авиарежиме.

Если пункта «На экран „Домой"» нет — вы в режиме приватного просмотра
или не в Safari.

На Android то же самое в Chrome: меню **⋮** → **Установить приложение**.

## Как пользоваться

- **← / →** — предыдущая и следующая неделя. На телефоне то же самое делает
  горизонтальный свайп по расписанию, на компьютере — стрелки на клавиатуре.
- **Сегодня** — вернуться на текущую неделю.
- **Поиск** — фильтрует по предмету, преподавателю, аудитории, типу занятия и подгруппе.
- Текущая пара подсвечивается зелёным с меткой «СЕЙЧАС» и обновляется сама, каждые 30 секунд.

## Как обновить расписание

### 1. Правка данных

Откройте `index.html` в любом текстовом редакторе. Данные — это блок с комментариями
`// ПОНЕДЕЛЬНИК`, `// ВТОРНИК` и так далее. Одна строка `add({...})` — одно занятие:

```js
add({day:3, start:'16:30', end:'18:05',
     subject:'Моделирование природных процессов в атмосфере',
     type:'Лекция',
     teacher:'зав. каф. Анискина Ольга Георгиевна',
     place:'ауд. 417, корпус 1 · Малоохтинский пр., 98',
     range:range('2026-09-02','2026-10-28')});
```

- `day` — день недели: 1 — понедельник … 7 — воскресенье.
- `range('с','по')` — занятие идёт **каждую неделю** в этом промежутке.
- `dates:['2026-10-21','2026-10-28']` — занятие идёт **только в эти дни**.
  Одно из двух обязательно, иначе занятие не покажется нигде.
- Необязательные поля: `group:'1 подгруппа'`, `online:true`, `note:true`
  (для строк вроде «Переезд на Металлистов»).
- Даты всегда в формате `ГГГГ-ММ-ДД`.

### 2. Поднять версию кэша

В `sw.js`: `const CACHE = 'map-m26-v1'` → `'map-m26-v2'`.

**Это обязательно.** Без смены версии на телефоне, где приложение уже установлено,
останется старая копия расписания.

### 3. Залить изменения

Через git — из папки с локальной копией репозитория:

```bash
git add .
git commit -m "Обновление расписания"
git push
```

Если локальной копии на этой машине ещё нет:

```bash
git clone https://github.com/Nerpa-ai/schedule.git
```

Либо, если под рукой только браузер, — через сайт GitHub:

1. Откройте <https://github.com/Nerpa-ai/schedule/tree/main/mapm26-raspisanie>
2. Нажмите на нужный файл → карандаш **Edit this file** справа вверху.
3. Вставьте новое содержимое → **Commit changes**.

Через минуту-две откройте приложение на телефоне — оно подтянет новую версию.

## Если сайт перестал открываться

Настройки Pages: <https://github.com/Nerpa-ai/schedule/settings/pages>

Должно быть: **Source** — `Deploy from a branch`, **Branch** — `main`, папка **`/ (root)`**.
Именно `/ (root)`, а не `/docs`: приложение лежит во вложенной папке, и Pages
раздаёт весь репозиторий целиком.

## Заметки

- **Репозиторий публичный** — иначе GitHub Pages не работает на бесплатном тарифе.
  В расписании есть ФИО преподавателей и номера аудиторий; это открытая информация
  с сайта вуза. Исходные PDF с расписанием в репозиторий не выкладывались —
  не коммитьте их случайно.
- **`.nojekyll` и `.gitignore` лежат в корне репозитория**, а не в этой папке:
  GitHub Pages ищет `.nojekyll` именно там, а `.gitignore` должен действовать
  на весь репозиторий. Через веб-интерфейс такие файлы не загрузить —
  проводник Windows не отдаёт имена, начинающиеся с точки, при перетаскивании
  в браузер; они добавлены через git.
- **Чередование «верхняя / нижняя» не показывается.** В исходном расписании
  колонка «Неделя (верхняя/нижняя)» пустая во всех строках — чередование задано
  перечислением конкретных дат. Отдельная таблица чередования недель охватывает
  период 29.12 — 19.07, то есть второй семестр, и к осени 2026 отношения не имеет.
- **Офлайн-режим работает только по http(s).** При открытии `index.html` напрямую
  с диска (`file://`) браузер не регистрирует service worker — это нормально,
  приложение всё равно работает, просто без кэша.
