# Расписание МАП-М26

Расписание 1 семестра 2026/27 группы МАП-М26 (РГГМУ, метеорологический факультет,
05.04.05 «Прикладная гидрометеорология», профиль «Моделирование атмосферных процессов»).

Одностраничное веб-приложение без сборки и без зависимостей: открывается двойным кликом,
ставится на домашний экран iPhone как обычное приложение и работает без интернета.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Всё приложение: разметка, стили, данные расписания и логика |
| `manifest.webmanifest` | Имя, иконки и режим запуска для установки на телефон |
| `sw.js` | Service worker: офлайн-режим |
| `icon-180.png` | Иконка для домашнего экрана iOS |
| `icon-192.png`, `icon-512.png` | Иконки для Android и манифеста |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

Период теоретического обучения: 01.09.2026 — 13.12.2026 (15 недель).
Занятия хранятся либо конкретными датами, либо диапазоном — как в исходном PDF,
поэтому пара не показывается после окончания своего периода.

## Публикация на GitHub Pages

Нужен бесплатный аккаунт на <https://github.com>. Адрес получится такой:

```
https://ВАШ-ЛОГИН.github.io/mapm26-raspisanie/
```

### Вариант А — через сайт, без установки git

Самый быстрый путь, git не нужен.

1. Откройте <https://github.com/new>.
2. **Repository name** — `mapm26-raspisanie`. Видимость оставьте **Public**
   (на бесплатном тарифе Pages работает только с публичными репозиториями).
   Галочку «Add a README file» **не** ставьте. Нажмите **Create repository**.
3. На странице пустого репозитория нажмите **uploading an existing file**.
4. Перетащите в окно браузера содержимое папки `mapm26-raspisanie`:
   `index.html`, `manifest.webmanifest`, `sw.js`, `icon-180.png`, `icon-192.png`,
   `icon-512.png`, `.nojekyll`, `README.md`.
   Перетаскивайте **файлы**, а не саму папку — иначе они лягут во вложенный каталог
   и адрес получится длиннее.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings** → в левом меню **Pages**.
   В блоке *Build and deployment*: **Source** — `Deploy from a branch`,
   **Branch** — `main`, папка `/ (root)`. Нажмите **Save**.
7. Подождите 1–2 минуты и обновите страницу Settings → Pages — вверху появится
   зелёная плашка со ссылкой. Это и есть адрес приложения.

### Вариант Б — через git

Если поставите git (<https://git-scm.com/download/win>), из папки
`mapm26-raspisanie` выполните:

```bash
git init -b main
git add .
git commit -m "Расписание МАП-М26: первая версия"
git remote add origin https://github.com/ВАШ-ЛОГИН/mapm26-raspisanie.git
git push -u origin main
```

Репозиторий на GitHub создайте заранее (шаг 2 варианта А), затем включите Pages (шаг 6).

## Установка на iPhone

1. Откройте адрес приложения **в Safari** (именно в Safari — Chrome на iOS
   не умеет добавлять сайты на домашний экран).
2. Кнопка **Поделиться** → **На экран «Домой»** → **Добавить**.
3. На домашнем экране появится иконка «МАП-М26». Приложение запускается
   на весь экран, без адресной строки.

После первого открытия расписание сохраняется в кэш и работает без интернета.

На Android — то же самое в Chrome: меню **⋮** → **Установить приложение**.

## Как пользоваться

- **← / →** — предыдущая и следующая неделя. На телефоне то же самое делает
  горизонтальный свайп по расписанию, на компьютере — стрелки на клавиатуре.
- **Сегодня** — вернуться на текущую неделю.
- **Поиск** — фильтрует по предмету, преподавателю, аудитории, типу занятия и подгруппе.
- Текущая пара подсвечивается зелёным с меткой «СЕЙЧАС» и обновляется сама, каждые 30 секунд.

## Как обновить расписание

1. Откройте `index.html` в любом текстовом редакторе (Блокнот подойдёт).
2. Найдите блок с комментариями `// ПОНЕДЕЛЬНИК`, `// ВТОРНИК` и так далее —
   это и есть данные. Одна строка `add({...})` — одно занятие:

   ```js
   add({day:3, start:'16:30', end:'18:05',
        subject:'Моделирование природных процессов в атмосфере',
        type:'Лекция',
        teacher:'зав. каф. Анискина Ольга Георгиевна',
        place:'ауд. 417, корпус 1 · Малоохтинский пр., 98',
        range:range('2026-09-02','2026-10-28')});
   ```

   - `day` — день недели: 1 — понедельник … 7 — воскресенье.
   - `range('с','по')` — занятие идёт **каждую неделю** в этом промежутке.
   - `dates:['2026-10-21','2026-10-28']` — занятие идёт **только в эти дни**.
     Одно из двух обязательно, иначе занятие не покажется нигде.
   - Необязательные поля: `group:'1 подгруппа'`, `online:true`, `note:true`
     (для строк вроде «Переезд на Металлистов»).
   - Даты всегда в формате `ГГГГ-ММ-ДД`.

3. **Поднимите версию кэша в `sw.js`**: `const CACHE = 'map-m26-v1'` → `'map-m26-v2'`.
   Без этого у телефона, где приложение уже установлено, останется старая копия.
4. Залейте изменённые файлы обратно: на сайте GitHub откройте файл → карандаш
   → вставьте новое содержимое → **Commit changes**. Или, если пользуетесь git:

   ```bash
   git add . ; git commit -m "Обновление расписания" ; git push
   ```

5. Через минуту откройте приложение на телефоне — оно подтянет новую версию.

## Заметки

- **Репозиторий будет публичным.** В расписании есть ФИО преподавателей и номера
  аудиторий — это открытая информация с сайта вуза. Исходные PDF в репозиторий
  не кладутся: они исключены в `.gitignore`. Если захотите хранить их рядом,
  уберите соответствующие строки из `.gitignore`.
- **Чередование «верхняя / нижняя» не показывается.** В исходном расписании
  колонка «Неделя (верхняя/нижняя)» пустая во всех строках — чередование задано
  перечислением конкретных дат. Отдельная таблица чередования недель охватывает
  период 29.12 — 19.07, то есть второй семестр, и к осени 2026 отношения не имеет.
- **Офлайн-режим работает только по http(s).** При открытии файла напрямую
  (`file://`) браузер не регистрирует service worker — это нормально, приложение
  всё равно работает, просто без кэша.
